# Бот записи клиентов

Telegram-бот для записи в барбершоп, салон или к мастеру. Подходит как первый проект для портфолио.

**Что умеет**
- клиент выбирает услугу, день и время (показывается только свободное время);
- оставляет имя и телефон (можно одной кнопкой);
- видит свои записи и может их отменить;
- получает напоминание о визите (за сутки, а если записался впритык — за 2 часа) с кнопкой отмены;
- администратор получает уведомления о новых записях и отменах, а командой `/bookings` смотрит все предстоящие записи.

**Технологии:** Python, aiogram 3 (FSM, inline-клавиатуры), SQLite.

## Как запустить

### 1. Создайте бота в Telegram
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте название бота и username (он должен заканчиваться на `bot`).
3. BotFather пришлёт токен — длинную строку вида `1234567890:AAH...`. **Никому его не показывайте**: с ним можно управлять вашим ботом.

### 2. Вставьте токен в файл `.env`
Скопируйте `.env.example` в новый файл `.env` (если его ещё нет) и вставьте токен после `BOT_TOKEN=`:
```
BOT_TOKEN=1234567890:AAH...
ADMIN_ID=
```

### 3. Запустите бота
При первом запуске установите библиотеки (в PowerShell, в папке проекта):
```
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
Затем запуск:
```
.\.venv\Scripts\python.exe bot.py
```
Появится строка «Бот запущен». Бот работает, пока открыто это окно. Остановить его можно сочетанием `Ctrl+C`.

### 4. Включите уведомления для себя
1. Напишите своему боту `/myid` — он пришлёт ваш ID.
2. Вставьте ID в `.env` после `ADMIN_ID=`.
3. Перезапустите бота (`Ctrl+C`, затем снова команда из шага 3).

## Автозапуск на Windows (бесплатно)

Чтобы бот сам запускался в фоне при входе в Windows, создайте задачу в Планировщике (PowerShell, в папке проекта):
```powershell
$dir = (Get-Location).Path
$action = New-ScheduledTaskAction -Execute "$dir\.venv\Scripts\pythonw.exe" -Argument "bot.py" -WorkingDirectory $dir
$trigger = New-ScheduledTaskTrigger -AtLogOn -User $env:USERNAME
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -ExecutionTimeLimit ([TimeSpan]::Zero) -RestartCount 999 -RestartInterval (New-TimeSpan -Minutes 1) -MultipleInstances IgnoreNew
Register-ScheduledTask -TaskName "BookingBot" -Action $action -Trigger $trigger -Settings $settings
```

Управление:
| Что сделать | Команда |
|---|---|
| Остановить бота | `Stop-ScheduledTask BookingBot` |
| Запустить бота | `Start-ScheduledTask BookingBot` |
| Убрать автозапуск | `Unregister-ScheduledTask BookingBot` |
| Посмотреть журнал | `Get-Content bot.log -Tail 30` |

После изменения кода перезапустите бота: остановите и снова запустите задачу.

Не запускайте бота вручную (`python bot.py`), пока работает задача: две копии с одним токеном мешают друг другу.

Бот работает, пока компьютер включён и не спит. Чтобы бот был доступен круглосуточно, нужен сервер (VPS).

## Как переделать под клиента

Всё основное лежит в `config.py`: название, контакты, услуги с ценами, рабочие дни и часы, время напоминаний.

## Устройство проекта

| Файл | Что в нём |
|---|---|
| `bot.py` | логика бота: что отвечать на каждое сообщение и кнопку |
| `keyboards.py` | кнопки |
| `db.py` | работа с базой данных (файл `bookings.db`) |
| `config.py` | настройки бизнеса |
| `.env` | секреты: токен и ID администратора (не выкладывать в интернет!) |

## Если что-то не работает
- **«Не найден BOT_TOKEN»** — токен не вставлен в `.env` или файл не сохранён.
- **Уведомления не приходят администратору** — администратор должен хотя бы раз нажать `/start` в боте.
- **Бот не отвечает** — проверьте, что окно с ботом открыто и в нём нет ошибок.
